# Video

The 105-second video at the top of the README: what a day with the assistant looks like, scene by scene (it
writes to you first, voice notes, the calendar, the home, email, errands, a trip, a shop, a team). Made with
[HyperFrames](https://github.com/heygen-com/hyperframes) (HTML compositions rendered to MP4). The music and sounds
were synthesised for it, so there are no third-party licences.

| File | What it is |
|---|---|
| `claudia.webp`, `claudia.es.webp` | What the README shows (English / Spanish): animated WebP, 480×854, 20 fps, the whole video, no sound, infinite loop. GitHub draws it inline and it plays by itself. |
| `claudia.mp4`, `claudia.es.mp4` | The full-quality video the animation links to: H.264 + AAC, 1080×1920, 30 fps, 104.6 s, with sound. Published at [https://jonjunq.github.io/claudia/video/claudia.mp4](https://jonjunq.github.io/claudia/video/claudia.mp4) (GitHub Pages serves `docs/`). |

GitHub strips `<video>` tags from READMEs, so the README uses an animated image linked to the MP4. Below WebP
quality 78 the dark gradients show blocks.

Everything in it is made up: the chats, the film, the hotel, the flights, the shop and the card ending in 1234.
Some scenes show things that are possible with this repo but optional or not tried by us yet (paying with a limited
card, answering a shop's customers, checking in with a team): see "What you can ask it" in the README.
